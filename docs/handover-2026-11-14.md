## 3. 이번에 만든 것

전부 `Plugins/GunDayCore` 안의 C++ 다. 잼 동안 2,495 줄을 더했다. 킷 파일은 고치지 않았다.

| 시스템 | 클래스 | 하는 일 |
|---|---|---|
| 외형 | `UGunDayAppearanceSubsystem` | 킷 마네킹을 숨기고 CitySampleCrowd 사람을 덧씌운다 |
| 시작·결과 화면 | `UGunDayFrontEndSubsystem` | 동영상 배경 타이틀, 내레이션 자막, 음악, 1분 판, 결과 화면 |
| 행인 반응 | `UGunDayCivilianReactionSubsystem` | 맞은 행인이 도망치거나 권총을 꺼내 반격한다 |
| 외침 | `UGunDayBarkSubsystem` | 형사·행인이 상황에 맞춰 한국어로 한마디 한다 (음성 50개) |

기존 시스템에서 바꾼 것.
- 범죄 감지: 게임 빌드에 없는 `ClassGeneratedBy` 대신 `CLASS_CompiledFromBlueprint` 로 블루프린트 클래스를 가린다.
  맞음·죽음 이벤트에서 외침을 부른다.
- 군중 반응: 반격하기로 한 행인은 도망치게 하지 않는다.
- 시비: 말다툼 첫 세 마디가 지나면 대사마다 외침이 섞인다.

### 외형이 붙는 방식

킷 AI 와 애니메이션은 UE4 마네킹 위에서 돈다. 그 마네킹을 숨긴 채 두고 아래 사슬로 동작을 옮긴다.

```
UE4 마네킹 (킷, 숨김)
  → 숨긴 UE5 Manny     ABP_MannequinUE4ToUE5Retarget
  → CitySampleCrowd 몸  ABP_MannequinUE5ToMetahumanRetarget
      ├ 옷   Leader Pose
      ├ 얼굴 ABP_CrowdCharacter_Head
      └ 머리카락 카드 메시를 머리 뼈에 붙인다
```

누가 어떤 모습인지는 `AppearanceRules` 가 정한다. Shotgunner 는 형사 둘(`형사_탈모`, `형사_수염`),
Civilian 은 군중 여섯, 플레이어는 하나. `형사_수염` 이 `VeteranAppearanceName` 이라 50대 형사 목소리를 쓴다.

### 설정 (`Config/DefaultGame.ini`, GunDay Core)

이번에 새로 생긴 값의 묶음이다. 전부 프로젝트 세팅에서 고친다.

- **외형**: `bApplyAppearances`, `AppearanceRules`, 리타깃 ABP 경로, `HairBoneName`
- **시작 화면**: `TitleTag`(DIRECTOR'S CUT 딱지), `TitleText`, `TitleBlurb`, `TitleMovie`, `TitleBackground`,
  `TitleNarration`, `TitleCaptions`(17줄, 시작·끝 초), `TitleMusic`·`TitleMusicVolume`
- **판과 결과**: `RoundSeconds`(60), `RoundStartWantedLevel`, `RoundMusic`·`RoundMusicVolume`,
  `SurvivedTitle`·`SurvivedLines`, `DiedTitle`·`DiedLines`, `ResultPrompt`
- **반격**: `FightBackChanceAtZeroJeong`(0.6)·`AtHighJeong`(0.15), `FightBackWeapons`(권총·리볼버)
- **외침**: `Bark*` 목록(경찰 도착·발견·교전·피격·쓰러짐, 50대 형사용 `BarkVeteran*`, 여자 행인, 반격 행인, 시비),
  `BarkVolume`(1.8), 쿨다운과 확률

## 4. 알아낸 것

- **패키지가 1 GB 를 넘는 주범은 텍스처다.** 첫 zip 이 1.68 GB 였다. `DefaultDeviceProfiles.ini` 에서
  LOD 그룹 16개의 `MaxLODSize` 를 1024 로 묶어 739 MB. 사람을 넣자 1.95 GB 로 다시 넘었고,
  군중 텍스처 1024 와 DNA 제거로 856 MB, 최종 805 MB.
  `DefaultEngine.ini` 와 디바이스 프로필의 strip-min-LOD 줄은 효과가 없었다. 남아 있지만 믿지 않는다.
- **회색 얼굴은 텍스처 슬롯 초과다.** 군중 얼굴 머티리얼이 SM5 한도 64 를 넘는 66 슬롯을 쓴다.
  복제본에서 Detail Normals 와 BakedRoughnessModulation 스위치를 끄면 들어간다.
- **LOD 를 지우는 스크립트는 에디터를 죽인다.** 그래서 DNA 만 지웠다.
- **Development 빌드는 방화벽 창을 띄운다.** Unreal Insights 추적(TCP 1985), UDP 메시징,
  ARKit 얼굴 추적 Live Link(UDP 11111) 가 포트를 연다. Shipping 으로 만들고 `DefaultEngine.ini` 에서
  `UdpMessaging EnableTransport=False`, `bEnableLiveLinkForFaceTracking=False` 로 두었다. 열린 포트 0 을 확인했다.
- **Shipping exe 이름은 `GunsKorea-Win64-Shipping.exe` 이고 창 제목 뒤에 공백이 붙는다.** 창을 찾는 스크립트가 여기서 틀렸다.
- **Shipping 은 로그를 남기지 않는다.** 원인을 봐야 하면 같은 코드로 Development 패키지를 만든다.
- **킷의 무기 추가 함수는 인수를 다 채워야 한다.** 기본값으로 부르면 무기만 들어오고 장착도 탄약도 없어
  반격하는 행인이 주먹만 썼다. AutoEquip, 탄약 수, 탄창 탄약까지 채운다.
- **월드가 막 시작될 때는 PlayerController 가 없다.** 시작 화면의 일시정지는 한 틱 뒤에 다시 시도한다.
- **시작 화면의 키 입력은 게임이 먼저 가져간다.** `IInputProcessor` 로 모든 키를 받고, 처리는 한 틱 뒤에 한다.
  일시정지 중에 돌아야 하는 일은 `FTSTicker` 에 건다.
- **Slate 글자 줄바꿈.** 가운데 정렬 슬롯에서 AutoWrap 이 한 단어씩 꺾인다. `WrapTextAt` 에 폭을 준다.
- **"가만히 있는데 수배가 오른다" 는 버그가 아니었다.** 게임 창에 포커스가 남은 채 다른 창에 타이핑하면 그 키가 총을 쏜다.
- **게임 소리는 Windows 기본 출력 장치로 나간다.** 헤드셋으로 듣는다면 그쪽이 기본 장치인지 본다.
- **게임 안에서 소리를 녹음하는 방법은 Shipping 에서 파일을 남기지 않았다.** 그 코드는 지웠다.
  플레이 영상은 내레이션과 음악을 맞춰 다시 입혔다. 총소리까지 담으려면 OBS 처럼 PC 출력을 통째로 녹음한다.
